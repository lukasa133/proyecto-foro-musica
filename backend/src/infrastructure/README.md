# Infrastructure

Esta carpeta contiene todo lo relacionado con las herramientas y tecnologías utilizadas por el proyecto.

Si algún día cambiamos una tecnología, la mayoría de los cambios ocurrirán aquí.

## Aquí irán

### Database

Configuración de Supabase y archivos relacionados con la conexión a la base de datos.

---

### Repositories

Implementación de los contratos definidos en Domain.

Aquí es donde realmente se consulta, inserta, actualiza o elimina información en Supabase.

---

### Config

Archivos de configuración del proyecto.

Ejemplos:

- Variables de entorno
- Configuración de Supabase
- Configuración de CORS
- Configuración de JWT
