# Frontend

Aplicación cliente de Foro de Música, creada con React y Vite.

## Requisitos

- Node.js 18 o superior.
- npm (se instala con Node.js).

## Ejecutar en desarrollo

```bash
cd src/frontend
npm install
npm run dev
```

Vite mostrará la URL local de la aplicación, normalmente `http://localhost:5173`.

## Scripts

- `npm run dev`: inicia el servidor de desarrollo.
- `npm run build`: genera la versión de producción en `dist/`.
- `npm run preview`: sirve localmente la versión generada con `npm run build`.

## Estructura

- `src/components/`: componentes reutilizables.
- `src/pages/`: páginas de la aplicación.
- `src/routes/`: definición de rutas.
- `src/services/`: comunicación con la API.
- `src/main.jsx`: arranque de React.
- `src/app.jsx`: componente principal.
