# Tests

Esta carpeta contiene las pruebas automatizadas del backend.

Con el crecimiento del proyecto podrán organizarse en diferentes categorías.

Ejemplos:

- Pruebas unitarias.
- Pruebas de integración.
- Pruebas de extremo a extremo (E2E).

## ¿Cuándo crear un archivo aquí?

Cuando desarrolles pruebas para verificar el correcto funcionamiento de la aplicación.
