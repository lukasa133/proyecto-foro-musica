# Código fuente

Esta carpeta contiene todo el código del backend.

El proyecto está organizado por responsabilidades para facilitar el mantenimiento y el crecimiento de la aplicación.

Cada carpeta cumple una función específica.

- **Domain:** representa el negocio.
- **Application:** coordina el funcionamiento de la aplicación.
- **Infrastructure:** contiene las tecnologías utilizadas.
- **Presentation:** gestiona la comunicación mediante la API.

Si tienes dudas sobre dónde crear un archivo nuevo, consulta el README de la carpeta correspondiente.
